# Homebrew Tap

Custom Homebrew formulae by [belaytzev](https://github.com/belaytzev).

## Install

```bash
brew tap belaytzev/tap
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `git-scoper` | Applies git user.name and user.email to every git repository found in a base directory |

### git-scoper

```bash
brew install belaytzev/tap/git-scoper
```
